# Code lịch sử

Đây là bản lưu notebook/generator/script trước refactor. Giữ để đối chiếu source và kết quả, không dùng làm runtime dependency của các notebook mới. Notebook đã được bỏ output; raw kết quả và trace vẫn nằm ở workspace cũ hoặc Kaggle. Không chạy các notebook rescue/continuation lịch sử như một baseline fresh.
